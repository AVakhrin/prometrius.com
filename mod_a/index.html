Prometrius Mod.A — Единая шина данных телеметрии для автотранспорта

Модульный аппаратно-программный комплекс сбора, нормализации и маршрутизации автомобильных потоков данных. Архитектура Mod.A агрегирует стандартную OBD2-диагностику, сырые шины CAN, датчики давления колес TPMS и спутниковый GSM-мониторинг в общий типизированный кэш для приборных панелей, спортивных хронометров и облачных систем аналитики.

Концепция: Local-First Telemetry Hub
Шина данных: Zero-Latency Memory Snapshot
Протоколы вещания: TCP / UDP / NMEA $RC3 / CAN v2
Безопасность: Hardware KeyStore (RSA-2048) + PIN-Gate

Каталог подсистем и аппаратных шлюзов

● Релиз v2.4 (Доступно)
01 / DIAGNOSTIC GATEWAY

OBD2 Gateway (PL.OBD2)

Высокоскоростной телематический шлюз-мультиплексор для адаптеров семейства ELM327. Ускоряет опрос параметров в 2–4 раза за счет конвейера ATSP6 и группировки запросов. Мгновенная раздача кэша клиентам Torque Pro, Car Scanner, RealDash и RaceChrono по сети со скоростью 1–2 мс.

02 / RAW BUS ACCESS

Direct CAN

Модуль прямого аппаратного подключения к шинам CAN / CAN-FD без накладных расходов протокола OBD-II. Непрерывный перехват сырых фреймов, трансляция кастомных PGN/CAN-ID, фильтрация широковещательных пакетов и прямая инжекция управляющих сигналов.

В разработке
03 / CELLULAR UPLINK

GSM / Cloud Telemetry

Автономный бортовой модуль удаленной телеметрии (TCU) на базе 4G/LTE. Передача географических координат, трековых заездов, диагностических параметров и аварийных событий в облачную платформу Prometrius Lab в режиме реального времени (MQTT/WebSocket).

04 / TIRE SENSORS

TPMS Bus

Аппаратный радиочастотный концентратор для опроса датчиков давления и температуры в шинах (RF 433/315 МГц и BLE TPMS). Прямая нормализация показаний колес и трансляция в виртуальные приборные панели RealDash без задействования штатной шины авто.
