Prometrius Mod.A — Unified Telematics Bus for Connected Vehicles

A modular hardware and software system for in-vehicle data acquisition, normalization, and multiplexed dispatching. The Mod.A architecture aggregates standard OBD2 diagnostics, raw CAN buses, wireless TPMS tire pressure sensors, and cellular GSM telemetry into a single typed memory cache for digital dashboards, lap timers, and cloud platforms.

Concept: Local-First Telemetry Hub
Data Pipeline: Zero-Latency Memory Snapshot
Output Protocols: TCP / UDP / NMEA $RC3 / CAN v2
Security: Hardware KeyStore (RSA-2048) + PIN-Gate

Hardware Gateways & Telematics Subsystems

● v2.4 Release (Available)
01 / DIAGNOSTIC GATEWAY

OBD2 Gateway (PL.OBD2)

High-speed telemetry gateway and multiplexer for ELM327-compatible adapters. Accelerates parameter polling rates by 2x–4x via the ATSP6 pipeline and request grouping. Delivers 1–2 ms cached response times to Torque Pro, Car Scanner, RealDash, and RaceChrono.

02 / RAW BUS ACCESS

Direct CAN

Hardware transceiver module for direct connection to vehicle CAN and CAN-FD buses bypassing OBD-II diagnostic protocol overhead. Unfiltered raw frame capture, custom PGN/CAN-ID transmission, and direct command signal injection.

Specification in progress
In Development
03 / CELLULAR UPLINK

GSM / Cloud Telemetry

Autonomous 4G/LTE telematics control unit (TCU). Provides real-time streaming of GPS coordinates, racing lap telemetry, engine states, and emergency events directly to the Prometrius Lab cloud platform via secure MQTT and WebSockets.

Specification in progress
In Development
04 / TIRE SENSORS

TPMS Bus

Dedicated RF receiver hub for decoding tire pressure and temperature sensors (433/315 MHz and BLE TPMS). Normalizes individual wheel metrics directly into RealDash digital instrument clusters without loading the vehicle's factory CAN bus.
