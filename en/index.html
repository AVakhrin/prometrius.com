Condition monitoring
for complex machinery

A deterministic platform for monitoring data from external sensors. An autonomous core, predictive analytics and an honest black box — on a microcomputer, a phone, a server rack or your car's head unit.

We measure — we don't guess. Accurate mathematical analysis needs no artificial intelligence, so we run on the simplest devices. A compact history needs no cloud, so we work locally, even where there is no internet. The result is available on any device, anywhere in the world, and is always predictable.

The core

The foundation of the product. The core does not know what it is measuring: it works with the structure of the data, while meaning comes from the model and the rules. One core therefore suits transport — a car, a boat, an aircraft — and industrial equipment: a machine tool, a pump station, a refrigeration unit. For transport it reads engine, gearbox and wheel data while you drive — the system watches for drift and warns in advance. In industry it watches machine tools, pumps and refrigeration units: signals converge on a server rack, and rules determine the condition of every unit.

Autonomous operation

The core lives independently of the interface: data collection and rule evaluation run continuously, even when the screen is off. Turn the phone off — the measurements continue.

Honest data

Our main principle. If a value did not arrive, you see it. If a source is unverified, it is marked. If the sample rate fell short, it is written to the journal — never silently substituted. An instrument you can trust must show its own weak spots.

Event-based control

Rules work with hysteresis, derivatives and time windows. The system notices a parameter drifting long before it becomes critical.

History from a second to a year

Three tiers of storage: recent data in detail, older data compactly, without losing the overall picture. Analyse a single trip second by second, and see the trend across a year.

The core works with different data models

A data model defines what is measured: the set of parameters, their units and their rates. Change the model and you change the industry. The core stays the same.

mod.A

Transport telemetry

A data model for passenger and commercial vehicles: engine, gearbox, brakes, wheels, temperatures, voltages. Works with in-vehicle buses and diagnostic protocols.

Sources and receivers can be extended

The core does not dictate where data comes from or where it goes. Sources and receivers are separate plug-in modules: some bring data from sensors and buses, others display, store or pass the result on.

Sources

Where data comes from: a diagnostic adapter, an in-vehicle bus, a machine's internal channel, external sensors. A source can be replaced without touching the core.

Receivers

Where the result goes: a device screen, a phone, a laptop, a server rack, third-party software. A receiver is connected as an extension.

For developers

The system provides an SDK, an API and emulators for building your own data models and extensions. Licensed separately.
